# Objective # 
Develop a Personal Finance dashboard using Power BI to visualize income, expenses, and savings trends. The project involved data import, transformation, and creating interactive visualizations to provide insights into spending habits and budgeting, facilitating informed financial decision-making.


# Project Details #

In my Personal Finance project using Power BI, I aimed to create an interactive dashboard to help users manage their finances effectively. The project began by importing financial data from various sources, including spreadsheets and databases, to consolidate income, expenses, and savings information.

Using Power Query, I transformed the data by cleaning, filtering, and structuring it for analysis. I created calculated measures for key performance indicators, such as total income, total expenses, and net savings, using DAX functions.

The dashboard features various visualizations, including bar charts, pie charts, and line graphs, to present spending patterns, monthly trends, and budget allocations. Interactive slicers allow users to filter data by categories, timeframes, and income sources. This project not only enhances financial awareness but also assists users in making informed budgeting and spending decisions.
